# Handbook AI Tutor（AI 智能学习助手）

把一份 **PDF 或 MP4 视频**交给它，它会自动帮你完成四件事：

1. **自动总结** —— 提炼全文摘要与大纲
2. **知识点梳理** —— 按章节拆出关键知识点
3. **出练习题** —— 生成选择题 + 翻译/写作/口语题，并给出解析
4. **AI 问答（Tutor Q&A）** —— 像老师一样回答你的问题，每条回答都附上原文出处（页码 / 时间戳）

全程本地运行，数据都保存在你自己的电脑上。

## 一、开始前：装两个软件（只装一次）

| 软件 | 说明 | 下载地址 |
| --- | --- | --- |
| Python | 版本 **3.11 或更高**，安装时**务必勾选 "Add Python to PATH"** | https://www.python.org/downloads/ |
| Node.js | 版本 **18 或更高**，选 **LTS 版**即可 | https://nodejs.org/ |

> 如果电脑上已经装过并能在命令行里运行 `python --version`、`node --version`，可跳过这一步。

---

## 二、第一次安装（只做一次）

1. 把项目文件夹放到你想长期存放的位置，例如 `D:\handbook-ai-tutor`。
2. 打开这个文件夹，在文件夹顶部**地址栏**里输入 `powershell` 然后回车，会弹出命令行窗口。
3. 把下面几行**依次**粘贴进去，每粘贴一行按一次回车：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e "./backend[dev]" -i https://pypi.tuna.tsinghua.edu.cn/simple
cd frontend
npm install
npm run build
cd ..
```

看到命令全部跑完、没有红色报错，就说明安装成功了。以后不用再重复这一步。

## 三、打开网站（每次使用）

- **启动**：双击项目根目录下的 **`start.vbs`**
  - 不会弹出黑色命令行窗口，后台自动启动，等几秒后会自动打开浏览器进入 **http://localhost:3000**
- **关闭**：双击 **`stop.bat`**

> 首次进入页面时，点右上角「注册」创建一个账号即可（账号、资料都只保存在本机，单人使用）。

---

## 四、默认配置说明（无需改动）

- 数据库、对象存储使用**默认账号密码**（如 `minioadmin/minioadmin`、`tutor/tutor`）。
  因为这是单人下载使用、不涉及多用户隔离，所以**默认值直接保留即可，不需要修改**。
- 数据存放位置：账号 / 资料 / 答题记录在 `backend\tutor.db`。每位用户在 `data\storage\<用户ID>\` 下有一个**专属文件夹**，注册并首次登录时自动创建，内含三层：
  - `profile\` —— 账号元数据（用户 ID、邮箱、注册时间；**不含密码**）
  - `records\` —— 该用户的学习记录存档（笔记、摘要、知识点、成绩与解析、问答、用量）
  - `resources\` —— 该用户导入的学习资源原件（文档 / 视频 / 音频）

## 五、（可选）接入真实 AI

默认使用「离线模拟」模型，不需要任何密钥就能跑通完整流程。想接入真实 AI（效果更好）：

1. 用**记事本**打开项目根目录的 `.env` 文件
2. 找到 `DEEPSEEK_API_KEY=`，在等号后面填上你的 Key，保存
3. 先双击 `stop.bat`，再双击 `start.vbs` 重启即可

> 密钥只保存在你本地的 `.env` 文件里，不会上传到任何地方（真实密钥已从项目里清空）。
> `.env` 必须用 **UTF-8** 保存。建议用 VS Code / Cursor 打开后右下角确认编码是 UTF-8，再保存。不要用系统记事本另存为 ANSI / GBK，否则中文注释会变成乱码。

## 六、常见问题

| 现象 | 解决办法 |
| --- | --- |
| 双击 `start.vbs` 打不开 | 确认已经完成「第一次安装」的 5 行命令，且 Python、Node 装好了 |

| MP4 练习题只考老师口头禅 / 课程安排 | 先确认资料已重新导入（本次会同时读语音和 PPT/板书画面），再点「生成练习题」 |

## 七、近期界面说明（原有功能都还在）

- **解析进度**：资料还在解析时，书架和原文页会走实时进度流（带登录态）。流断开时才退回原来的轮询。
- **文本来源**：摘要旁边会标明 OCR / 语音转写是真实识别还是离线模拟，避免把 mock 逐字稿当成课堂原文。
- **引用跳转**：Tutor 回答里的出处可以点，左侧原文预览会跳到对应页或时间戳。Quiz 解析里的「跳到原文」同样回到这份资料。
- **练习题**：重新生成会**另存一套新题**，旧题和作答记录还在。提交后可以对错题单独再练。口语题按你输入的文本对照参考答案批改，**不做语音识别评分**。
- **用量**：设置页和资料页可以看到每个任务、每份资料用了多少 token（不换算金额）。

### 本次改进（视频课 Quiz / 中文编码）

- **MP4 不只听语音**：导入视频时会抽取 PPT / 板书关键帧并做文字识别，再和老师讲解按时间对齐。练习题依据**课件上的知识点和讲解内容**出题，不再把老师口头禅、寒暄、课程时间安排当成考点。
- **旧视频要重新导入**：这次改的是解析流程。已经导入过的 MP4 需要在原文页重新导入（或重新上传）后，再生成一套新题，才会带上画面内容。
- **`.env` 统一 UTF-8**：配置文件和程序读取都按 UTF-8，避免中文注释在 Windows 下变成乱码。
- **Tutor Q&A 乱码修复**：回答、引用摘录入库前会尝试还原常见的中文乱码（例如 UTF-8 被当成 GBK 读过一遍的情况）。修复只认多字符乱码片段，**不会改掉**「浣溪沙」「璇玑」「妯娌」这类正常词。
- **同类项目调研**：近一个月 GitHub 上 PDF/视频学习、Quiz、Q&A 项目的整理见 `docs/github-learning-platform-research-2026-09.md`（含 OpenMAIC、RagVault、RAG-Anything、ByteLearn 等；部分仓库只核实到 push 日期、主线代码未必同期更新）。

启动 / 关闭方式不变：双击 `start.vbs` 打开 http://localhost:3000，双击 `stop.bat` 关闭。

## 八、练习题：多次生成与删除

> 这一节说明「反复生成练习题」之后，怎么把不要的题组删掉，以及删了会怎样。

### 功能描述

- 每点一次「重新生成」，都会**另存一套新题**，不会覆盖旧题组；旧题组和它们的作答记录都还在。
- 练习题页右侧会列出这份资料的全部题组（新的排在最上面），**每一套都可以单独删除**。
- 删除有两种方式，区别只在于**作答记录要不要一起清掉**：

| 方式 | 操作 | 结果 |
| --- | --- | --- |
| 保留成绩删题 | **不勾选**「同时删除该题组的作答记录」 | 题目与解析被移除，题组从列表消失；但该题组的历史作答记录仍留在下方「提交记录存档」里，还能点开看。适合「这套题不要了，但想留着当时的成绩」 |
| 彻底删除 | **勾选**「同时删除该题组的作答记录」 | 题目、作答记录、题组本身一并**彻底删除，不可恢复** |

- 目前是**逐套删除**（一次删一套），没有「一键清空全部题组」的功能；要删多套就重复操作即可，多次删除互不影响。

### 操作步骤

1. 打开某份资料 → 点上方「练习题」进入练习题页。
2. 在右侧题组列表里找到要删的那一套，点它右边的「删除」。
3. 弹窗会显示题组名称、题目数、章节数和生成时间；确认无误后按需勾选：
   - 想把成绩记录也一起清掉 → **勾选**「同时删除该题组的作答记录」；
   - 只想删题、保留成绩 → **不要勾选**。
4. 点「确认删除」。成功后页面会出现一条提示，写明移除了多少道题（以及多少条作答记录）。

### 注意事项

- **删除不可恢复**：题目与解析会随题组一并消失，删之前请确认清楚。
- **只影响这一套**：其他题组、原文、摘要、知识点、Tutor 问答都不受影响；删完随时可以再点「重新生成」得到新的一套。
- 如果删掉的正好是**当前正在看的那一套**，页面会自动切到剩下的最新一套；一套都不剩时回到空态。
- 若某题组**还留有作答记录**、而你没有勾选「同时删除作答记录」，系统不会把题组整行抹掉，而是把它标记为「已删除」隐藏起来——这样存档里的旧成绩还能显示题组名称。**勾选后才会真正整行删除。**
- 删除是**按题组**进行的，不能只删某一道题。
